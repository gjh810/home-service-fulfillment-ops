# 家电上门服务履约监控与异常闭环

个人服务运营分析作品集项目。参考京东校招服务运营岗位描述，设计工单履约流程、指标口径和异常闭环规则，并生成合成工单验证分析方法。**本项目不使用京东真实工单；所有数据、概率和站点差异均为演示假设。**

## 当前内容

| `03_模拟工单.csv` / `03_模拟工单.xlsx` | 600 条合成工单；Excel 版可直接用于筛选和数据透视表 |

## 核心口径

只统计预约上门与承诺完工截止时间都已过去的有效工单。准时上门率、按期完工率、投诉率以全部有效工单为分母；异常闭环率以有异常工单为分母。主要异常按派单、上门、完工的流程顺序记录最早失约环节，不能代替其他指标。

## 复现数据

在本目录运行：

```text
node generate_orders.mjs
python validate_orders.py
python analyze_exceptions.py
```

生成脚本只使用 Node.js 内置功能，校验脚本只使用 Python 标准库。CSV 使用 UTF-8 BOM，便于在 Excel 中打开；Excel 版时间字段为日期时间值。参数和样本指标见 `03_模拟数据说明与验收.md`。

第 4–7 天已完成数据质量检查、逐单计算、原生城市数据透视表、分组分析和履约看板。工作簿中的公式汇总随现有 600 行源数据修改而重算；原生透视表需手动刷新，新增行需扩展公式及引用范围，具体见 `05-07_看板使用与分析说明.md`。第 8–9 天已完成异常定位、原因假设、待闭环分级、处理 SOP 和改善试点设计；这些建议尚未在真实业务中执行或验证。模拟结果只用于展示分析过程，不代表任何企业的实际履约表现或改善成效。
